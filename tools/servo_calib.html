一次只接一只舵机，点它的通道，然后按下面的按钮让它来回摆两次。摆了 → 硬件全通；不摆 → 先查供电，别急着调 trim。

📖 展开：舵机完全不动时的完整排查清单（8 条 · 默认收起）
⓪ 先做这一条（最常见）：量到 ≈0.2V 是好消息，但舵机在 1500µs 本来就不动！
直流档读到 0.08~0.41V 区间 = PWM 波形完全正常（3.3V × 1500µs / 20000µs = 0.248V）。 可 0.2V 恰好是站姿 1500µs（舵机中位） —— 舵机臂本来就在中位时，给它中位脉宽就是保持不动。 务必先敲 pwm 0 2500（或点下面「通电自检」、cal 0 40）让它偏离中位： 电压应升到 ≈0.41V、舵机应转，测完 pwm off。没做这步之前，"舵机不动"很可能只是还没让它动过。
⚡ 点动后电压变了、舵机仍不动，才按这个顺序查：
① PCA9685 的 V+ 端子没接 5V，或电源开关没开 —— 烧写时特意让你先别开舵机电源，标定前要记得开。芯片自己靠 VCC(3.3V) 工作，所以 V+ 没电时串口、status、命令回显全都正常，只有舵机没劲，极具迷惑性。万用表量 V+ 对 GND 应有 5V。
② 没有三方共地：适配器 GND、PCA9685 GND、ESP32 GND 必须连在一起。
③ OE 没接到 GND：OE 是低电平使能，拉高会关掉全部 16 路输出；不少板子悬空会被拉成高电平，请直接用杜邦线把 OE 接 GND（早期接线图误写成"悬空即可"，已更正）。同时确认：舵机三线没插反（棕=GND / 红=V+ / 橙=信号）、插的是 0~7 号排针， 并看清板子通道三根针的丝印顺序——各家不同（有的 PWM/V+/GND，有的 GND/V+/PWM）， 别只按舵机线颜色盲插。
两步定位法：
④ 敲 cal 0 40 再敲 status。CH0 舵机角变成 111°（90 + 40 − 19）→ I²C 已把脉宽写进芯片，软件链路全通；还是 90° 才是固件/命令问题。注意这只证明芯片收到数据，不等于引脚真的在输出（OE 拉高时芯片照样应答）。
⑤ 验引脚：把 LED 串 470Ω 接在 0 号通道信号脚 ↔ GND，敲 pwm 0 1500 应微亮、pwm 0 2500 明显变亮（测完 pwm off）。LED 不亮 → OE/VCC 问题；LED 会亮但舵机不动 → 舵机 5V 供电或线序问题。
⑥ 信号脚量到恒定 ≈3.3V 是不正常的：正常 PWM 用直流档只该读到 0.08~0.41V （pwm 0 500≈0.08V、pwm 0 1500≈0.25V、pwm 0 2500≈0.41V）。 恒 3.3V = 输出被禁用呈高阻 / 量错脚（SDA、SCL 空闲时同样被上拉到 3.3V）/ 固件配置错。
⑦ 2026-11-08 已定位并修好的固件 bug：旧版把 PCA9685 的位定义写反了 （把 MODE1 的 AI 当成 SLEEP、把 MODE2 的 INVRT 当成 AI），导致 PRESCALE 停在默认 200Hz、 输出极性反转、4 字节连写全塌到同一寄存器 → pcadiag 会显示 PRESCALE=30、ON=OFF。正确读数必须是 MODE1=0x21 (AI=1)、MODE2=0x04 (INVRT=0)、 PRESCALE=121、CH0 ON=0 OFF≈307。 四项全对才算固件没问题；不全对说明板子里还是旧固件，需重新烧写。
⑧ 最后一种可能：信号峰值只有 3.3V。PCA9685 输出的高电平来自 VCC（本项目接 ESP32 3V3）， 不是 V+ 的 5V。有些 MG90S 在 5V 供电下要求信号 >3.5V，3.3V 会完全不响应 （micro:bit 那类方案常把 VCC 接 5V，输出 5V 峰值，所以能驱动）。 ⚠ 千万别为了提幅值把 VCC 直接改接 5V：SDA/SCL 会被上拉到 5V 打到 ESP32 的 GPIO8/9。 真要解决得加 3.3V→5V 电平转换模块（如 74AHCT125），或先量一下 SDA 空闲电压确认板子有没有电平转换。
先 OE→GND，再敲 pwm 0 500 与 pwm 0 2500 各量一次， 两次应差约 0.33V；纹丝不动就点下面「📡 读芯片寄存器」看四项判读。

「回到站姿」点了不动是正常的：板子上电就一直停在当前站姿，再喊一次"站直"角度没有任何变化。想看到舵机动，请用上面的自检按钮，或拖 ④ 的 trim 滑块。
注意：2026-11-13 起站姿改成「膝 −48° / 髋 24°」，比装配基准更弯 10°，所以 8 路舵机角不再是 90°+trim（髋 +5°、膝 −10°），但 trim 值本身完全没变、不用重标。

③ 装机前基准：确认脉宽范围 & 站立中位

这一步在装机械腿之前做：先弄清这只舵机「从多少 µs 到多少 µs」，再把它停在装腿基准，然后保持通电把腿装上去。用的是裸脉宽 pwm，绕过 trim/dir；测试范围已放宽到 500~3000µs（需烧写 11-11 版固件，否则超过 2500 会被固件拒绝）。

⚠ 先分清「360° 舵机」是哪一种，这决定能不能装腿：
A · 位置舵机（大行程、能停在指定角度）：给 1700µs 会转到一个角度就停住 → 可以用；大行程型号的满程端点常超过 2500µs，必须实测。
B · 连续旋转舵机（其实是减速电机）：给 1700µs 会一直转不停，1500µs 只是「停转」而不是某个角度 → 没有位置保持能力，装机械腿会一直转，不能用。
下面所有「转了多少度」的推算只在 A 类成立。点「判别舵机类型」：发 1700µs 保持 3 秒再回 1500µs，盯住它停不停。
转一下就停 = 位置舵机；一直转 = 连续旋转舵机
「1500µs 该是 90° 还是 180°？」两个说法都没错，量的不是同一个东西：
固件里的「90°」是它自己用的内部刻度（0~180 半量程），不是舵机轴真实转过的角度 —— 固件只把内部角度换算成脉宽，并不知道舵机物理上转了多少度。
若波段是 500~2500µs ↔ 0~360°，1500µs 在物理上确实是 180°；本机实测波段就是 500~2900µs， 1500µs 只对应 (1000/2400)×360 = 150°，连物理中点都不是。
所以装腿不必追求「物理 180° 中点」：我们人为把「腿站直」定在 1500µs，固件上电也发 1500µs，两边一致就不会跳。真正要改的是下面算出来的 us_span。

② 停在装腿基准，装机械腿

装腿要点：让舵机停在 1500µs 并保持通电，再把舵机臂／机械腿装到该有的站立姿势 （膝 −38° → 髋 19°，髋轴离地 104mm）。装完点 pwm off 回到步态控制。
「去实测中点」只用来看看物理中位在哪，别拿它装腿：固件上电默认发 1500µs， 若按实测中点（比如 1700µs）装腿，一退出 raw 就会转回去，腿就歪了。
别让舵机顶在 500 / 3000µs 超过几秒（堵转发热）。pwm 期间步态被冻结， 不 pwm off 的话 ④ 的 trim 滑块不会生效。固件把裸脉宽硬限在 500~3000µs， 端点若还在这之外，需要再放宽 SERVO_US_CMD_MAX 并重烧。

🔎 电压对了但舵机不动？做这三点测量

黑表笔始终点在舵机的棕线（GND）上，不要点板子 GND —— 只有以舵机自己的地为参考，量到的才是舵机真正"看到"的电压。

先理解「电压一直在 0.40、没有波动」：万用表直流档显示的是 50Hz 方波的平均值， 稳定不跳是正确的（方波太快，万用表跟不上；想看跳动要切交流档/频率档或用示波器）。 pwm 0 1500≈0.25V、pwm 0 2500≈0.41V —— 从 0.2V 升到 0.40V 恰恰证明命令生效、引脚输出在跟随， ESP32 → I²C → PCA9685 → 通道引脚这一段已经全部正常，不用再查程序或重烧固件。
#红表笔 / 档位正常值不达标说明
①点舵机红线（V+），直流电压档稳定 5V（≥4.8V）舵机根本没电：V+ 电源没开 / 端子到排针 V+ 不通 / 三根线插反

为什么以前一点 dir 舵机就乱转？固件里 dir 是乘在「关节角 − 站立基准角」上的系数，不是独立开关。 站姿时这个差 = 0，翻转不会改变舵机角；但只要板子还停在 cal 手动点动、walk 步态、 或刚退出 pwm 还在回位途中，差值 ≠ 0，翻转就会把腿镜像到另一边，舵机猛地转过去， 同时 20ms 任务正在刷新 8 路，看起来像「别的舵机也在动」。

🔄 改 us_span 后的 trim 换算（2000 → 1200，默认收起）
站姿时 脉宽 = 1500 + trim × us_span / 180。固件把 us_span 从 2000 改成 1200 后（实测 500~2900µs = 360°，跨度 ÷ 2），同一个 trim 发出的脉宽会缩小，站姿会偏。要让脉宽保持不变： 新 trim = 旧 trim × 旧 span ÷ 新 span = 旧 trim × 1.6667。
使用顺序：先烧写新固件 → 点下面「📋 读取板子状态」取回 NVS 里的旧 trim（快照） → 点「写入换算值 + save」。换算后脉宽不变，舵机应该不跳； 若发现腿还是歪，用 ④ 的滑块肉眼重拖一遍更稳。
数据源是「读取板子状态」那一刻的快照，重复点写入不会累积放大；改过滑块请重新读取。
⚠ 这个换算整个项目只做一次： 若 status 里 trim 已经是 −41.7 / −43.3 / +30.0 这类换算后的值 （2026-11-11 助手已通过串口完成并 save），不要再点「写入换算值」， 否则会把 trim 再放大 1.6667 倍、站姿全歪。本工具留给「以后换舵机 / 重调 span」时复用。
⚠ 2026-11-13 起站姿不再等于装配基准： 现在站姿脉宽 = 1500 + (站姿偏移 + trim) × span / 180（髋 +5°、膝 −10°）， 上面的换算公式假设偏移为 0，以后真要重调 span 时不能直接套用。

⑦ 完整标定流程（照着做）

  1. 只接一只舵机（比如 0 号 = 左前髋）。8 只全插上，一旦方向反了会同时撞限位。打开 5V 电源、确认三方共地；用电池盒时先量带载电压（发命令瞬间不能掉到 4.8V 以下）。
  2. 连上板子 → 选中这只舵机的通道 → 点「通电自检」。它会用 cal 让这只舵机来回摆 2 次。摆了才继续；没摆就按 ② 的黄框查 V+ / 共地 / OE / 线序，别往下调。
  3. 装机前基准（③）：先点「判别舵机类型」确认它是位置舵机（不是一直转的连续旋转舵机）；再用脉宽滑块从 500 慢慢推到 3000（须先烧写 11-11 版固件），必要时用「📐 线性外推」估出该往哪个脉宽找端点；找到「刚开始动」和「刚到头」两个脉宽，分别点「记为最小 / 最大端点」；然后点「回装腿基准 1500µs」，保持通电把机械腿装到站立姿势；装完点 pwm off。「去实测中点」只用来观察，别拿它装腿。
  4. 判方向：自检时看它是往前还是往后摆。也可在命令框敲 cal 0 40 单独确认， 判完先敲 cal off 回站姿。方向反了 → 点「方向 dir」翻转成 −1 （按钮会再自动归位一次并等待姿态收敛，翻转瞬间舵机不该动），再自检一次确认。
  5. 调 trim：拖滑块，舵机会跟着转，看到这只腿摆到该有的站立姿势就停手。这个值就是这一路的 trim。当前站姿是膝 −48° / 髋 24°（比装腿时的 −38°/19° 更弯 10°），认准这个姿势即可，装配基准与 trim 都不用改。
  6. 换下一只舵机、选对应通道，重复 2~4 步。全部 8 路调完 → 点「保存」，看到「标定值已写入 NVS」才算成功。
六个坑：
⓪ 点「回到站姿」看不到动作是正常的：上电后本来就一直站在这个姿势，角度没变，舵机当然不动。要看动作必须发会改变角度的命令（自检按钮 / cal / trim）。
① trim 上限已放宽到 ±50°（与固件 SERVO_TRIM_LIMIT_DEG 一致）：本机 8 只 360° 舵机的装配基准整体偏移， 换算 span 后髋需要到 −43° 左右。这只是软件夹紧量，动作幅度不受影响；若仍不够，说明舵机臂物理装歪了， 应把臂拔下来重插到 1500µs 站姿位置，让 trim 回到几度的小误差。
② pwm / pwmscan 发的是"裸脉宽"，绕过 trim/dir，只能验证线有没有波形，不能用来判方向。判方向请用 cal。
③ 改 dir 之前先回站姿（cal off / pose stand / pwm off），④ 的按钮已自动处理。 固件 11-13 起翻转 dir 会用「保持当前输出脉宽不变」反解新 trim，翻转瞬间舵机不该动； 但 trim 数值会跟着变（方向反了，补偿值当然要变），这是正常的，不是标定丢了。 翻转后记得 save，否则掉电会回到旧的 dir/trim。
④ 别用手掰舵机臂，8 只同时堵转会超出 3A 供电能力。
⑤ 360° 位置舵机的角度映射已修好：本机实测 500~2900µs = 360°， config.h 的 SERVO_US_SPAN_DEFAULT 已从 2000 改成 1200（= 实测跨度 ÷ 2）， 重烧后 1° 指令 = 1° 物理角，步态 IK、软限位、600°/s 限速全部对齐。 SERVO_US_MID_DEFAULT 仍 1500、装腿仍按 1500µs； 1500µs 不是本波段的物理中点（只对应 150°），但装腿不需要物理中点。
