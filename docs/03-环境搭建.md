## 2. 安装路径规划

```
E:\esp\
├── esp-idf\            # ESP-IDF 源码（v5.5.5，Gitee 镜像）
└── .espressif\         # 工具链 + Python 虚拟环境（IDF_TOOLS_PATH，约 1.5~2GB）
```

> 合计占用约 2.5~3GB（含后续 build 缓存）。E 盘充裕，且**源码必须在英文无空格路径**下。

## 3. 安装方式（二选一）

### 方式 A：一键脚本（推荐，我提供的自动化脚本）

在 **Windows PowerShell**（不是 CMD）中执行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
cd C:\Users\aaron\WorkBuddy\spider8
.\tools\install_esp_idf.ps1
```

脚本自动完成：前置检查 → Gitee 镜像克隆 v5.5.5 → 安装 esp32s3 工具链 → 校验 `idf.py --version`。
预计耗时 15~30 分钟（取决于带宽，主要时间在下载工具链）。

### 方式 B：官方 Windows 安装器（最省心，图形界面）

1. 下载：https://dl.espressif.com/dl/esp-idf/ → 选择 **ESP-IDF v5.5.5** 的 Windows Installer（Online）
2. 安装向导中 **修改安装目录为 `E:\Espressif`**（默认 C 盘空间不够）
3. 版本勾选 **v5.5.5**，组件全选（含工具链、Python、Git）
4. 安装完成后从开始菜单打开 **"ESP-IDF 5.5 PowerShell"** 即可用

> 两种方式二选一即可，不要同时装（会有 IDF_PATH 冲突）。

## 4. 每次开发前的「激活」方式

ESP-IDF 的环境变量需要先激活，三选一：

| 方式 | 操作 |
|---|---|
| 命令行（推荐） | 每次开新终端执行：`E:\esp\esp-idf\export.ps1` |
| 桌面快捷方式 | 新建快捷方式，目标：`powershell -ExecutionPolicy Bypass -NoExit -Command "E:\esp\esp-idf\export.ps1"` |
| VSCode 插件 | 见第 6 节，插件自动激活，无需手动 export |

激活成功标志：终端提示符前出现 `(esp-idf)`，`idf.py --version` 有输出。

## 5. 串口驱动（接板子前必做）

ESP32-S3 开发板的 USB 口通常是以下之一，**先确认板子上那颗芯片的丝印**：

| 芯片丝印 | 驱动下载 |
|---|---|
| CP2102 / CP2104 | https://www.silabs.com/developer-tools/usb-to-uart-bridge-vcp-drivers |
| CH343 / CH9102 | https://www.wch.cn/downloads/CH343SER_EXE.html |
| ESP32-S3 原生 USB（USB-Serial/JTAG） | Win10/11 一般免驱；若识别不出用 Zadig 装 WinUSB |

验证：插上板子后 `设备管理器 → 端口(COM和LPT)` 出现 `COMx` 即正常。

**常见坑**：USB 线是"充电线"（只有电源没数据线）→ 电脑识别不到设备。换一根数据线再试。

## 8. 常见坑速查

| 现象 | 原因 | 解决 |
|---|---|---|
| `idf.py: command not found` | 未执行 export 脚本 | 先跑 `export.ps1` |
| `install.ps1 无法加载，因为在此系统上禁止运行脚本` | PowerShell 执行策略 | `Set-ExecutionPolicy -Scope Process Bypass` |
| 编译报 `ninja: error` / 路径乱码 | 工程路径含中文或空格 | 工程必须放英文无空格路径 |
| `PYTHONPATH` 报错 | 与其它 Python 环境冲突 | `Remove-Item Env:PYTHONPATH` 后重试 |
| 烧写失败 `Failed to connect` | 未进下载模式 / 串口被占用 | 按住 **BOOT** 键再点 RESET 松开；关闭其它串口软件 |
| 下载工具链超时 | github 资源慢 | 脚本默认走 `dl.espressif.com`；必要时挂代理 |
| 克隆超时 | github 慢 | 用脚本里的 **Gitee 镜像**（默认已配） |
| `install.ps1` 装依赖报 wheel 构建失败 | PATH 里的 Python 是 3.14+，超出 IDF 支持范围 | 脚本已内置自动选择（会挑 3.13）；也可手动 `-PythonExe "C:\...\python.exe"` 指定 |
| 脚本报"禁止运行脚本" | 执行策略限制 | `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` |
| 脚本中文乱码 | .ps1 需 UTF-8 **BOM**（PS 5.1 特性） | 本项目脚本已带 BOM；自己新写脚本时注意保存为 UTF-8 with BOM |
