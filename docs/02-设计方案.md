# Spider8 设计方案（基于已确认需求 v1.0）

> 版本：v0.1 ｜ 日期：2026-09-28 ｜ 上游文档：`01-需求分析.md`（D1~D4 已确认）  
> 选型基线：ESP32-S3-N16R8 ｜ 8×MG90S（PWM）｜ HC-SR04 ｜ BLE 微信小程序 ｜ 乐高 Technic 结构

---

## 1. 系统总体架构

```
┌─────────────────┐   BLE GATT (NUS)   ┌──────────────────────────────┐
│  微信小程序       │ ◄───────────────► │  ESP32-S3-N16R8 固件           │
│  · 虚拟摇杆       │   摇杆包/命令/遥测   │  ┌────────┐ ┌──────────────┐  │
│  · 动作按钮       │                    │  │BLE服务  │ │ 步态引擎 gait  │  │
│  · 舵机微调设置   │                    │  └────────┘ └──────┬───────┘  │
└─────────────────┘                    │  ┌────────┐ ┌──────▼───────┐  │
                                       │  │避障状态机│ │ 舵机驱动 LEDC │──┼─► 8×MG90S
                                       │  └────────┘ └──────────────┘  │
                                       │  ┌────────────────────┐       │
                                       │  │ 动作播放器(关键帧JSON) │       │
                                       │  └────────────────────┘       │
                                       └───────┬───────────┬──────────┘
                                               ▼           ▼
                                           HC-SR04     ADC 电量采样
```

三层解耦：**手机端（UI/交互）↔ BLE 通信层（协议）↔ 固件运动层（步态/动作/安全）**。运动层不感知控制来源，遥控、自动避障、动作播放统一走「目标关节角指令队列」。

## 2. 硬件设计

### 2.1 引脚分配（ESP32-S3）

| 功能           | GPIO                       | 说明                              |
| ------------ | -------------------------- | ------------------------------- |
| 舵机 CH0~CH7   | 4, 5, 6, 7, 15, 16, 17, 18 | LEDC 8 通道，50Hz，14-bit 分辨率       |
| HC-SR04 TRIG | 38                         | 推挽输出 10µs 触发                    |
| HC-SR04 ECHO | 39                         | **必须分压**（1k/2k）降到 3.3V          |
| 电池电压 ADC     | 10                         | ADC1_CH9，33k/10k 分压（8.4V→1.95V） |
| WS2812 眼睛 ×2 | 48                         | RMT 驱动，多数 S3 开发板板载              |
| 板载 RGB 状态灯   | 48                         | 复用，颜色表示模式                       |

> 避开 strapping 引脚（0/3/45/46）与 UART0（43/44），预留 GPIO 1/2/9/11/12 给后期扩展（蜂鸣器、IMU）。

### 2.2 电源架构

```
2S 18650 (7.4V, 2×2600mAh, 带2S保护板)
 ├─► DC-DC 5V/5A（XL4015 或 mini560 5A）──► 舵机电源轨（8×MG90S）
 │        └─ 并联 2200µF 低ESR电解电容（吸收堵转电流尖峰）
 └─► 5V 轨 ──► AMS1117 3.3V ──► ESP32-S3 / HC-SR04
电池组 ──► 33k/10k 分压 ──► GPIO10 电量采样
```

**关键点**：

- 舵机轨与主控轨**分开**，堵转电压跌落不会导致 MCU 复位；
- MG90S 按 5V 供电（扭矩 2.2kg·cm，够用），8 路同时爬行实测电流约 2~3A，峰值按 5A 冗余设计；
- 低压阈值：3.4V/cell（6.8V 总压）报警趴下，3.3V/cell 强制停机。

### 2.3 乐高结构方案

- **乐高兼容舵机支架**（淘宝有售 3D 打印的乐高孔位舵机座，MG90S/SG90 规格）+ Technic 梁/销拼装；
- 机身：中央矩形框架放电池+主控，四角各出一条 2 关节腿（髋:水平摆 ±45°，膝:抬放 0~90°）；
- 腿末端用 Technic 轮胎/光滑销做脚垫，增大摩擦；
- 重心尽量低：电池（最重件）置于机身底层平面。

## 3. 软件架构（ESP-IDF + FreeRTOS）

### 3.1 任务划分（静态创建，栈大小经水标验证）

| 任务              | 优先级 | 栈    | 周期    | 职责                          |
| --------------- | --- | ---- | ----- | --------------------------- |
| `servo_task`    | 6   | 2048 | 事件驱动  | 唯一写 LEDC 的任务，消费关节角队列，做软限位裁剪 |
| `gait_task`     | 5   | 4096 | 20ms  | 步态引擎：波步/小跑插值，输出 8 关节目标角     |
| `ble_task`      | 4   | 4096 | 事件    | NimBLE 主机，解析摇杆/命令包，发遥测      |
| `action_task`   | 4   | 4096 | 事件    | 关键帧动作播放器（JSON 帧序列 → 关节角）    |
| `obstacle_task` | 3   | 3072 | 100ms | 超声波测距 + 避障状态机（仅自动模式激活）      |
| `monitor_task`  | 2   | 2048 | 1s    | 电量采样、WS2812 状态灯、低压保护        |

**模式仲裁**（互斥，防止动作打架）：`IDLE / MANUAL遥控 / AUTO避障 / ACTION动作播放 / PROTECT保护`，由一个事件组（EventGroup）管理，优先级 PROTECT > ACTION > MANUAL > AUTO。

### 3.2 运动学与步态设计

**单腿 2 自由度模型**（无逆运动学求解器，用查表+参数化，8DOF 足够简单直接）：

- 髋关节 C（coxa）：摆动 ±45°，决定步幅方向
- 膝关节 F（femur）：抬起 0°（收腿离地）↔ 90°（伸直支撑）

**波步（Wave Gait，最稳）**——任意时刻仅 1 条腿摆动，3 腿支撑：

```
相位表（步态周期 T 分 8 拍，步长 S）：
摆动顺序: 左前 → 右前 → 左后 → 右后
每腿: 2 拍摆动(抬起-前摆-落下) + 6 拍支撑(随身体相对后移 S/6)
```

- 前进：摆动相前摆 +S；转向：左右两侧步长差动 ΔS；
- 参数：步长 S（速度）、周期 T、抬腿高度 H，均由 BLE 下发可调；
- 小跑（Trot，对角两腿同摆）作为 M3+ 的提速选项。

### 3.3 BLE 协议（Nordic UART Service + 简洁二进制帧）

服务：NUS `6E400001-B5A3-F393-E0A9-E50E24DCCA9E`（微信小程序 BLE 直接兼容）。

**下行（手机→机器人，≤20B/包）**：

| 类型   | 帧格式                                                       |
| ---- | --------------------------------------------------------- |
| 摇杆   | `0xA1 \| x:int8 \| y:int8 \| seq` （50ms 间隔心跳，500ms 断连→停车） |
| 模式   | `0xA2 \| mode(0x00手动/0x01自动/0x02停止)`                      |
| 动作   | `0xA3 \| action_id` （查本地动作库）                              |
| 舵机微调 | `0xA4 \| ch \| trim:int8` （持久化 NVS）                       |
| 姿态预设 | `0xA5 \| pose_id` （站立/趴下/高姿/低姿）                           |

**上行（遥测，1Hz）**：`0xB1 \| battery:mV/10 \| mode \| dist_cm \| seq`

### 3.4 组合动作库（关键帧 JSON，存储于 LittleFS/SPIFFS）

```json
{ "id": 1, "name": "wave_hello", "loop": 2,
  "frames": [
    { "t": 0,    "j": { "fl_c": 0,  "fl_f": 60 } },
    { "t": 200,  "j": { "fl_c": 35, "fl_f": 60 } },
    { "t": 400,  "j": { "fl_c": -35, "fl_f": 60 } },
    { "t": 600,  "j": { "fl_c": 35, "fl_f": 60 } },
    { "t": 800,  "j": { "fl_c": 0,  "fl_f": 90 } } ] }
```

- `t`=毫秒时间点，`j`=各关节目标角，帧间线性插值 50Hz 平滑过渡；
- 内置动作：`wave_hello 挥手 / lie_down 趴下 / twist 扭屁股 / dance 小碎步 / threat 威吓（抬前腿前倾） / nod 点头卖萌`；
- 动作可由小程序下发新增/覆盖（OTA 之外的第二扩展通道）。

### 3.5 避障状态机（无 降级方案）

```
CRUISE(直行) ──dist<25cm──► STOP ──► BACK(退 1s) ──► TURN(随机左/右转 90°±30°)
   ▲                                                      │
   └────────────────── 恢复直行 ◄──────────────────────────┘
连续 3 次避障未脱离 → 播放 threat 动作后原地换向 180°（脱困策略）
```

无 IMU 的替代安全措施：**一键趴下**（紧急停止+低压保护共用）、堵转时间窗（同方向持续输出 >1.5s 未达行程 → 回中休息 2s，防 MG90S 烧毁）。

## 4. 微信小程序设计

| 页面  | 功能                                    |
| --- | ------------------------------------- |
| 连接页 | 扫描过滤设备名 `Spider8-XXXX`，连接后自动订阅 NUS TX |
| 遥控页 | 虚拟摇杆（触摸事件映射 x/y）+ 模式开关（手动/自动）+ 速度滑条   |
| 动作页 | 动作按钮网格（挥手/趴下/扭屁股/跳舞/威吓/点头）+ 姿态预设      |
| 设置页 | 舵机 8 通道微调（trim 滑条，写入 NVS）、步态参数、电量显示   |

技术要点：`wx.openBluetoothAdapter` → `createBLEConnection` → 写 NUS RX 特征值；摇杆 50ms 节流上报。

## 7. 设计风险与对策回顾

| 风险                         | 对策（已内置于设计）                   |
| -------------------------- | ---------------------------- |
| MG90S 无反馈，堵转烧毁             | 软限位 + 堵转时间窗切断 + 电源大电容        |
| 无 IMU，跌倒无法自恢复              | 一键趴下/复位 + 避障保守参数（低速、提前转向）    |
| 小程序 BLE 在 iOS/Android 表现差异 | 统一 NUS 协议 + 心跳超时停车兜底         |
| 乐高结构关节旷量                   | 摆动相幅度留 10% 余量，落地拍加重插值        |
| 8 舵机共轨干扰                   | 独立 5V/5A 舵机轨 + 主控 AMS1117 隔离 |
