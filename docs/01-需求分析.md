# 四足蜘蛛机器人「Spider8」需求分析

> 项目代号：Spider8 ｜ 文档版本：v0.1（待确认）｜ 日期：2026-09-28  
> 主控平台：ESP32-S3-N16R8（双核 Xtensa LX7 @240MHz，16MB Flash，8MB PSRAM，WiFi 2.4G + BLE 5.0）

---

## 1. 项目概述

制作一只**四足仿蜘蛛机器人**，每条腿 2 个关节（共 8 个舵机），支持：

- 手机遥控（方向、速度）
- 自动爬行 + 避障
- 多组"可爱系"组合动作（打招呼、跳舞、趴下卖萌等）
- 按软件工程流程推进：需求分析 → 设计方案 → 原型迭代

| 序号 | 部件    | 方案                        | 说明                                     |

## 3. 功能需求

### FR-1 手机遥控（P0 必做）

- 虚拟摇杆控制：前进/后退/左转/右转，模拟量调速
- 步态切换：慢速漫步（Wave/四步）↔ 快速小跑（Trot/两步）
- 支持单腿微调（调试模式）

### FR-2 自动爬行避障（P0 必做）

- 自动模式：直线爬行，前方 20~30cm 检测到障碍 → 停止 → 后退/转身绕行
- 卡死检测：IMU 异常姿态或舵机电流异常（若选总线舵机）→ 触发脱困动作

### FR-3 组合动作库（P0 必做）

| 动作    | 描述                  |
| ----- | ------------------- |
| 打招呼   | 抬起一只前腿左右挥动          |
| 趴下/起立 | 身体降低贴地 ↔ 恢复站姿       |
| 扭屁股   | 身体左右摇摆 + 重心左右转移     |
| 小碎步跳舞 | 原地快速交替点脚            |
| 威吓    | 抬起前两腿 + 身体前倾（蜘蛛感拉满） |
| 眨眼卖萌  | LED 眼睛动画 + 轻微点头     |

- 动作以"关键帧序列"存储（JSON 表），可扩展新增动作而无需改代码

### FR-4 姿态控制（P1）

- 站立高度调节、身体俯仰/横滚微调

### FR-5 系统功能（P1）

- 舵机中位校准流程（首次使用必做）
- 低电压报警 + 自动趴下保护
- OTA 固件升级（利用 16MB Flash 双分区）

### FR-6 可扩展（P2 备选）

- 红外跟随/手势、声音音效库、摄像头（ESP32-S3 支持）留接口

## 4. 非功能需求

| 类别  | 指标                                        |
| --- | ----------------------------------------- |
| 实时性 | 舵机 PWM 更新 50Hz，步态插值周期 20ms，遥控指令延迟 < 100ms |
| 续航  | ≥ 30 分钟连续爬行（2S 18650 ×2）                  |
| 载荷  | 每个关节扭矩余量 ≥ 2 倍静态需求                        |
| 稳定性 | 舵机堵转不导致主控复位；看门狗兜底；跌倒可自恢复                  |
| 内存  | FreeRTOS 静态分配任务栈，8MB PSRAM 存放动作帧缓存        |
| 成本  | 整机目标 ¥300~600（视舵机方案）                      |

## 5. 约束与风险

| 风险                  | 影响               | 对策                        |
| ------------------- | ---------------- | ------------------------- |
| 8 舵机同时动作电流峰值可达 5~8A | 电池/降压模块过载、电压跌落复位 | 大电容缓冲 + 独立舵机供电轨 + 软启动限流   |
| PWM 舵机无反馈，堵转烧毁      | 舵机损坏             | 限位保护、堵转时间窗切断（若选总线舵机则可读电流） |
| 8DOF 四足静态步态重心不稳     | 爬行倾翻             | 慢速波步（三足支撑），重心轨迹插值         |
| 3D 打印件强度不足          | 关节旷量、断裂          | 增加加强筋、金属舵机臂、M3 尼龙锁紧螺丝     |

## 7. 我的建议（Better Ideas 💡）

1. **强烈建议考虑串行总线舵机（如 LX-16A / STS3215）**：虽贵约 ¥100~200，但带**位置/电压/温度回读**，可以做堵转保护、动作录制回放（像玩偶一样手动摆姿势→自动录制），避障的"卡死检测"也更可靠。入门预算紧则 MG90S 也完全可行。
2. **ToF（VL53L0X）替代超声波**：体积小、无盲区、不受软质障碍（布料）反射干扰，对蜘蛛这种小机身更友好，I2C 与 MPU6050 共总线不占 IO。
3. **手机端用 WiFi AP + Web 虚拟摇杆**：无需安装 APP，手机连上机器人热点即玩；后续再加 BLE 做低延迟双模。
4. **Web 动作编辑器**：在控制页面里做一个"关键帧编辑器"，拖滑块摆姿势→保存为新动作，让"可爱动作"可以由你自己持续创作，这是本项目最有趣的增值点。
5. **掉电安全姿态**：任何异常（低压/翻倒）先趴下再保护，比直接断电对舵机和机械都友好。

## 8. 决策点（已确认 ✅ 2026-09-28）

| 编号 | 决策项      | 结论                       | 备注                                      |
| -- | -------- | ------------------------ | --------------------------------------- |
| D1 | 关节舵机     | **MG90S/SG90 PWM 舵机** ×8 | 金属齿轮 MG90S 更耐用；无反馈 → 需软限位+堵转时间窗保护       |
| D2 | 手机控制方式   | **BLE 蓝牙小程序**            | 微信小程序 wx.createBLEConnection + 虚拟摇杆，免安装 |
| D3 | 避障/姿态传感器 | **仅超声波 HC-SR04**         | 无 IMU → 无跌倒自恢复，改为「一键趴下/复位姿态」按钮          |
| D4 | 结构件      | **乐高（Technic 积木）版本先行**   | 乐高兼容舵机支架 + 积木拼装，结构迭代零等待，后续可换 3D 打印外壳    |

> 保留建议（后期可升级）：串行总线舵机（带反馈/动作录制）、ToF 测距、IMU 跌倒自恢复、Web 动作编辑器。
