① 总览地图：这套程序是什么？

把它想象成机器狗的神经系统。你在电脑上打字下命令，它把命令变成 8 路电脉冲，舵机收到就动起来。

一句话定位

你在外面打字 → console.c 听命令 → motion.c 算目标 → servo.c 翻译成电脉冲 → pca9685.c（或 LEDC）写到硬件 → 8 路舵机动。

文件人体部位一句话作用
main.c🐣 出生流程按正确顺序把各模块"叫醒"
config.h🧬 基因/参数表几条腿、腿多长、舵机接哪个脚、转多少度算限位
console.c👂 耳朵+嘴听你打的命令（如 walk 50），也把状态汇报给你
motion.c🧠 大脑决定"该站/该走/该握手"，定时算出 8 个关节目标角
gait.c📐 数学脑纯算账：脚要抬到哪 → 髋和膝各转几度
servo.c🔌 神经把"关节角"翻译成"脉宽"，并加三道保护
pca9685.c💪 肌肉接口I²C 扩展板，把电脉冲送到舵机线（当前后端）

两个"实时循环"（FreeRTOS 任务，每 20 毫秒各转一次）：

motion_task（大脑·优先级5） 算"8 个关节下一刻该转多少度"
servo_out_task（神经·优先级7·更急） 从队列拿最新目标，写到舵机

它们用一条"只存最新一条"的队列连接。好处：万一大脑卡住，神经仍按"最后一条目标"保持姿势，不会乱抽。

⑤ 核心三件套：motion → gait → servo 详解

这三个文件就是机器狗"会动"的全部秘密。大脑 motion.c 决定每一步要什么角度，数学脑 gait.c 把"脚要去哪"算成"关节转几度"，神经 servo.c 把角度翻译成电脉冲送出去。下面逐个拆开，文末有一张可筛选的函数级调用链。

🧠 motion.c —— 大脑（指挥 + 节拍器）

维护三种模式（POSE 姿态 / WALK 步态 / MANUAL 手动），每 20ms 算好 8 个关节角，写进一条"只留最新"的队列。

  • 核心motion_init()：初始化步态参数，创建长度 1 的队列 s_q（覆盖式，永远只留最新目标）。
  • 核心motion_start()：创建两个 FreeRTOS 任务 motion_task（prio 5）和 servo_out_task（prio 7），都用 vTaskDelayUntil 跑 20ms 节拍（不是 vTaskDelay，否则节拍会越跑越慢）。
  • 核心motion_tick()：单拍逻辑。WALK→调 gait_output()；POSE→调 pose_compute()；MANUAL→直接复制标定角。再 rate_limit()（每拍每关节最多 11°，550°/s），最后 xQueueOverwrite(s_q)。
  • gait_output() → 调 gait_step() 算本拍 8 个角；pose_compute() → 调 gait_solve_static()（蹲/趴/握手/挥手，脚永远解到地面）。
  • 对外接口：motion_walk() / motion_pose() / motion_stand() / motion_manual() / motion_set_speed/turn/period/stride/lift/duty()。
  • 调用谁：gait.c（gait_step, gait_solve_static）、servo.h（servo_apply，经队列）
    被谁调用：console.c、main.c（init/start）
static void motion_tick(void) {
    float raw[J_COUNT];
    if (s_mode == MODE_WALK) {
        gait_output(s_tick, raw);        // 调 gait.c 算本拍角度
        s_tick++;
    } else {
        s_pose_ms += GAIT_TICK_MS;
        pose_compute(s_pose, s_pose_ms, raw); // 调 gait.c 解姿态
    }
    rate_limit(s_out, raw);              // 每拍每关节最多 11°（550°/s）
    xQueueOverwrite(s_q, &tgt);      // 交给 servo_out_task
}

📐 gait.c —— 数学脑（纯算账，不碰硬件）

两连杆正/逆运动学。已知"脚的目标位置 (y, z)"，反解"髋转几度、膝转几度"。只依赖 config.h 的腿长常量，绝不碰任何硬件。

  • 核心gait_step(p, tick, tpc, &out)：按相位表 PATTERN_PHASE 给每条腿算相位；摆动相用余弦缓动抬脚、支撑相线性后移；逐腿调 gait_ik2() 填 out->hip_deg / knee_deg。
  • 核心gait_ik2(y, zdown, &hip, &knee, &clamped)：两连杆逆解（余弦定理），膝角强制取负（统一向后折）。
  • gait_solve_static(knee_deg, foot_y, foot_lift, hip[], knee[])：给定屈膝角（决定机身高度），解全部腿。
  • gait_hip_for_knee() / gait_height_for_knee()：屈膝角 ↔ 髋角 / 离地高度的解析关系。
  • gait_estimate()：仿真一整圈，估算峰值角速度是否超过 MG90S 的 600°/s。
  • 相位表（真实）：WALK {64,192,0,128}（后腿先动：RL→FL→RR→FR）；TROT/PACE/BOUND 各两条腿同步。
  • 调用谁：只依赖 config.h 腿长常量
    被谁调用：motion.c；servo.c 初始化（站立基准用 gait_hip_for_knee / gait_height_for_knee）
// gait_step 内：对每条腿 l
uint8_t ph = base + PATTERN_PHASE[pattern][l];
if (ph < swing_end) {                 // 摆动相：抬脚
    float s = (1 - cosf(PI*u)) * 0.5f;
    y    = -stride + 2*stride*s;
    lift = lift_mm * sinf(PI*u) * sinf(PI*u);
} else {                               // 支撑相：脚贴地匀速后移
    y    = stride - 2*stride*u;
    lift = 0;
}
gait_ik2(y, hip_h - lift, &hip, &knee, &clamped); // 逆解
out->hip_deg[l]  = hip;
out->knee_deg[l] = knee;

🔌 servo.c —— 神经（角度→电脉冲 + 三道保护）

把"关节角"翻译成"PWM 脉宽"，再交给后端（LEDC 或 PCA9685）写出。上层完全不知道底下是哪个后端。

  • 核心servo_init(joint[])：用 gait_hip_for_knee / gait_height_for_knee 算站立基准（髋 19°/膝 -38° = 舵机 90°），读 NVS 标定，调 backend_init()，摆初始姿态。
  • 核心servo_apply(joint[], cal_mode)：每拍被 servo_out_task 调用，逐关节过三关再写。
  • servo_joint_to_servo(j, a)：关节角 → 舵机角（90° 基准 + dir 镜像 + trim 微调）。
  • servo_write_us(j, us) → backend_write_us()：真正写硬件（LEDC 或 PCA9685）。
  • servo_raw_us/enter/exit：raw 电气测试通道（冻结正常步态）；servo_save_cal/load_cal：NVS 存 trim/dir。
  • 三道保护（都在 servo_apply 内）：① 软限位（关节角夹在 lim_min~lim_max）② 电子硬限位（舵机角锁 0~180°）③ 单拍限速（20ms 最多走 12° = 600°/s）。
  • 调用谁：gait.h（站立基准）、backend（pca9685.c / ledc）
    被谁调用：servo_out_task 经队列 → servo_apply；console.c 的 raw 模式
// servo_apply 内：逐关节过三关
for (int j = 0; j < J_COUNT; j++) {
    float a = joint_deg[j];
    if (!cal_mode) {                       // ① 软限位
        if (a < lim_min) a = lim_min;
        if (a > lim_max) a = lim_max;
    }
    float sv = servo_joint_to_servo(j, a); // 关节角 → 舵机角
    if (sv < 0)   sv = 0;                 // ② 电子硬限位
    if (sv > 180) sv = 180;
    float d = sv - s_servo[j];             // ③ 单拍限速 12°（600°/s）
    if (d > SERVO_MAX_STEP_DEG) sv = s_servo[j] + SERVO_MAX_STEP_DEG;
    if (d < -SERVO_MAX_STEP_DEG) sv = s_servo[j] - SERVO_MAX_STEP_DEG;
    servo_write_ch(j, sv);                // → backend_write_us
}

⑨ 舵机标定：trim / dir（装配误差怎么补）

舵机臂很难正好插准，左右脚装法还常常相反。固件用两个参数吸收这两类误差：trim（微调偏移）和 dir（方向镜像）。标定一次存进 NVS，断电不丢。

核心公式（servo.c 第 73 行）

舵机角 = 90° + (关节角 − 基准角) × dir + trim

  90°    舵机机械中点（装配时把臂插在它的 90°）
  关节角  算法想让该关节转到的角度（髋0=竖直向下；膝0=伸直）
  基准角  站立时该关节角度：髋 19°、膝 −38°（代码写死，8 路统一）
  dir    方向镜像：+1 / −1（左右脚装法相反时给一侧设 −1）
  trim   装配误差微调：−50° ~ +50°（臂没插准时补偿；2026-11-11 由 ±30° 放宽）

两个参数对照

你说的现象参数范围命令
某只舵机要转到 60°/30° 才是站立位（臂没插准）trim−50°~+50°trim <0-7> <-50..50>
同命令左前脚前转、右前脚后转（左右镜像）dir1 / −1dir <0-7> <1|-1>

⚠ 两个坑

  • pwm / pwmscan 是"裸脉宽"，绕过 trim/dir（servo.c 的 servo_raw_us 注释写了不走 trim/dir/软限位）。只能验证"线有没有波形"，不能判方向；判方向用 cal。
  • 改完 dir/trim 必须 save，否则断电重启回到默认 +1 / 0，白调。
