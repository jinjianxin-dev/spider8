# 09 · 舵机接线与首次上电

> 适用：8 × MG90S + ESP32-S3-N16R8，乐高 Technic 结构。
> 读完这一页再通电，能避免 90% 的"舵机一抖板子就重启"。

---

## 0. 一句话结论

**舵机的电源绝对不能从开发板取。** 开发板只用 USB 供电（给芯片和逻辑），
舵机用一路独立的 5V 电源，两者**必须共地**（GND 连在一起）。

---

## 1. 为什么不能用开发板的 5V

MG90S 的电流不是恒定的，它跟负载强相关：

| 状态 | 单只电流 | 8 只合计 |
|---|---|---|
| 静止保持（无外力） | 约 5~10 mA | 40~80 mA |
| 正常转动 | 约 150~250 mA | 1.2~2 A |
| **堵转（顶死/卡住）** | **约 700 mA** | **5.6 A** |

开发板的 5V 来自 USB。USB 2.0 口标准只给 **500 mA**，主板好一点也就 1 A 左右，
再经过板上的二极管/走线，还要打个折。8 只舵机一动，电压瞬间被拉到 3V 以下：

- 轻则 ESP32 触发 brownout 复位（现象：串口突然打印一堆 `rst:0x3 (RTC_SW_SYS_RST)`
  或直接重来一遍启动日志，机器人"抽一下"）
- 重则 USB 口保护、开发板反复重启，长期这么干会损伤稳压器

所以这不是"能不能凑合"的问题，是**必然出问题**。

---

## 2. 供电方案（已选定：5V/3A 电源适配器）

### 2.1 为什么是它

判据只有一条：**看瞬时电流能力，不是平均电流**。8 只 MG90S 单只堵转约 700mA，
8 只同时堵转就是 **5.6A**；正常走路平均只有 1~1.5A，但每次换向都有 2~3A 的尖峰。
电源一软，ESP32 立刻 brownout 重启。

| 方案 | 瞬时能力 | 成本 | 结论 |
|---|---|---|---|
| **5V/3A 适配器** | ★★★★ | 20~30 元 | ✅ **选定**，台面调试最稳 |
| 充电宝 5V/2A↑ | ★★☆ | 家里可能有 | ⚠️ 多数产品过流保护在 2.4A 左右，8 只同时动会**直接断电**，机器人瞬间趴下。要用必须挑明确标注 3A 以上的 |
| 4 节 AA 电池盒 | ★★ | 5 元 | 便宜，但碱性电池内阻大，一换向电压就跌到 5V 以下，续航约 40 分钟 |
| 2S 锂电 + UBEC | ★★★★★ | 40~60 元 | 最终形态才需要，要配充电器和过放保护 |

> 选 A 的理由很实际：**调试时本来就拖着 USB 看串口**，再加一根电源线没有额外负担。
> 等整机走通、要拿到地上跑，再上 2S 锂电也不迟，A 还能留着当台面电源。

### 2.2 采购清单（一次买齐）

| 物料 | 数量 | 说明 |
|---|---|---|
| 5V/3A 电源适配器（DC 5.5×2.1 圆头） | 1 | **认准 5V**，别买成 12V |
| DC 母座转接线端子 | 1 | 把圆头转成可插杜邦线的正负极 |
| 电解电容 **1000µF / 10V** | 1 | 并在舵机电源两端。**这颗别省** |
| 接线端子排 或 小面包板 | 1 | 把 8 根红线并成一条 5V 母线、8 根棕线并成一条 GND 母线 |
| 自恢复保险丝 3A（可选） | 1 | 串在 5V 正极上，接错线时不至于烧板 |

**强烈建议加那颗电容**：它像个小水库，舵机瞬间要电流时先由它顶上，
能显著减少"一动就复位"。

> MG90S 额定 4.8~6.0V。低于 4.5V 扭矩明显变软、动作发飘；高于 6.5V 会烧电机。

## 3. 接线表

舵机三根线的颜色（MG90S）：

| 颜色 | 含义 | 接到 |
|---|---|---|
| 棕 / 黑 | GND | 电源负极（同时与开发板 GND 相连） |
| 红 | VCC | **独立 5V 正极** |
| 橙 / 黄 | 信号 | 对应 GPIO |

信号脚分配（与固件 `config.h` 一一对应）：

| 通道 | 关节 | GPIO | | 通道 | 关节 | GPIO |
|---|---|---|---|---|---|---|
| CH0 | 左前髋 FL | 4 | | CH4 | 左后髋 RL | 15 |
| CH1 | 左前膝 FL | 5 | | CH5 | 左后膝 RL | 16 |
| CH2 | 右前髋 FR | 6 | | CH6 | 右后髋 RR | 17 |
| CH3 | 右前膝 FR | 7 | | CH7 | 右后膝 RR | 18 |

> 这 8 个脚在 ESP32-S3 上都不与 Flash / PSRAM / USB 冲突，可以放心用。
> 不要用 GPIO 0/3/45/46（strapping 脚，上电电平会影响启动）。

## 4. 接线步骤（**全程断电**）

1. **拔掉 USB**，确认开发板没有电（板上的电源灯灭）
2. 把 8 只舵机的**红线和棕线**分别并到电源正极和负极（并联，不是串联）
3. 把 8 只舵机的**橙线**按上表插到对应 GPIO
4. **把开发板的 GND 与舵机电源负极连一根线**——这一步最容易忘，忘了必然乱抖
5. 电容并在电源两端（注意正负极，反接会炸）
6. 复查一遍，再插 USB

> 第一次通电建议**先只接 1~2 只舵机**，确认没问题再上全部 8 只。
> 8 只同时上电的冲击电流最大，分批接能避免一开始就撞上电源极限。

### 上电顺序（有讲究）

```
1. 先插 USB  → 开发板启动，8 路已稳定输出 90°
2. 等 5 秒   → 直到串口出现 spider8> 提示符
3. 再开舵机电源 → 舵机一上电就直接朝 90° 走，不会乱甩
```

反过来先开舵机电源也不会坏，但会发生一件事：**信号线还没输出，舵机会因为找不到
基准而集体抽搐一下**。开环舵机都有这个毛病，不是故障，但看着吓人，也容易顶到结构。

## 5. 上电前检查清单

用万用表，逐条确认（没有万用表就用眼睛复查）：

- [ ] 舵机电源正负极**没有短路**（红黑之间电阻应为几十欧以上，不是 0）
- [ ] 电源电压在 **4.8~6.0V** 之间
- [ ] 开发板 GND 与电源负极**导通**（万用表蜂鸣档响）
- [ ] 8 根信号线没有插错位、没有插到电源脚上
- [ ] 电容正负极没接反
- [ ] 舵机臂**还没装**，或者装在能自由转动的角度

---

## 6. 首次上电验证流程

按顺序做，每一小步都观察舵机反应是否平滑、串口是否重启。

**第 1 步：只看不动**

```
status
```

期望：8 个通道都显示 `舵机角 90.0°`，`运行 Ns` 在正常累加。
如果这时串口就在反复打印启动日志——说明电源有问题，立刻断电检查。

**第 2 步：单关节微动 5°**

```
cal 0 24
```

CH0 是左前髋。站立姿态下它的关节角是 19°，改成 24° 就是**向前转 5°**。
期望：这只舵机平滑转一点点，没有"嗡嗡"抖动，串口不重启。

**第 3 步：转回来**

```
cal 0 14
```

应该往回转 5°，经过中位。两次都顺滑，说明这一路 OK。

**第 4 步：确认方向对不对**

髋角增大 = 腿**向前**摆。如果方向反了（增大反而向后），不要拆装，用：

```
dir 0 -1
save
```

**第 5 步：逐个通道过一遍**

把 `cal <0-7> 24` / `cal <0-7> 14` 对每一路都试一次。
膝关节（CH1/3/5/7）注意：站立是 **−38°**，往 −33° 是**伸直**、往 −43° 是**更弯**。

**第 6 步：退出标定，试整体姿态**

```
cal off
pose crouch
pose stand
```

这两个动作会让 8 只舵机同时动，是真正考验电源的一步。
如果这里出现重启，就是电源电流不够，换 3A 以上电源或加分批上电。

## 7. 常见故障对照

| 现象 | 最可能的原因 | 处理 |
|---|---|---|
| 舵机不停"嗡嗡"抖、微微震 | 电源电压不足或有干扰 | 换 3A 电源，加 1000µF 电容 |
| 一动作串口就重启 | 舵机抢电流，brownout | 舵机改用独立电源；确认共地 |
| 某一路完全不动 | 信号线松/插错脚；该通道没供电 | 换一个已知好的通道试这只舵机，交叉验证 |
| 舵机往反方向转 | 装配方向反了 | `dir <j> -1` 再 `save` |
| 转到某个角度就顶死不回 | 软限位没生效或结构干涉 | 立刻断电，检查机械干涉；缩小动作幅度 |
| 上电瞬间所有舵机猛地一跳 | 正常（开环舵机上电找不到位置） | 属正常现象；装结构前一定先标定中位 |
| 只有第 1 只动，其他不动 | 信号线只插了一根 | 逐根复查 |

## 8. 安全红线

1. **不许从开发板 5V 给舵机供电**（第 1 节已说明）
2. **不许把 7.4V 锂电直连舵机**
3. **舵机卡住时不要硬撑**——堵转 3 秒以上就会烫手，长时间会烧线圈
4. **装配舵机臂前必须先标定中位**：现在固件里 90° = 站立姿态，
   把腿摆成站立姿势，再把舵机臂装到 90°，后面所有动作才对得上
5. 调试时**手边留一只手能随时拔 USB**
6. ⚠️ **接上舵机后禁止再用 `pwmscan`**。它直接输出 500~3000µs 的全行程扫描，
   **绕过全部软限位**——舵机臂装上以后就是把关节往机械限位上顶，很容易扫齿。
   LED 阶段可以用（LED 没有限位），舵机阶段一律用 `cal` 小步点动。

---

## 9. 与原计划的衔接

接好线、跑通第 6 步之后，就可以：

- 按 `08-LED与PWM验证.md` 的思路做电气确认（此时可以直接看舵机反应，不必用 LED 了）
- 进入 **M1 校准**：把 8 个通道的中位和方向逐个调准，`save` 写进 NVS
- 之后才是装腿、装结构、验证站立与步态
