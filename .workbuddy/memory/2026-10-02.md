## 踩坑记录（重要，后续复用）
1. **Windows PowerShell 5.1 的 .ps1 必须带 UTF-8 BOM**，否则中文按 GBK 误读导致引号错位、语法报错（"意外的标记 }"）。本项目脚本已用 `utf-8-sig` + CRLF 保存，后续新增 .ps1 必须同样处理。
2. ESP-IDF 5.5 官方支持的 Python 为 3.9~3.13；本机 PATH 默认 3.14.6 会导致装依赖失败 → 安装脚本已内置 Python 版本自动筛选（把受支持版本提到 PATH 首位）。
3. 工具限制：不能用 Bash 调 powershell.exe（安全策略拦截）；Start-Job 后台作业也被拦截 → PowerShell 工具输出捕获异常时，改为「脚本写文件 + Read 读取」的方式拿结果。
