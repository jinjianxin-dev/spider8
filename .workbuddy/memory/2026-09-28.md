# 2026-09-28 工作日志

## Spider8 四足蜘蛛机器人项目启动
- 完成需求分析 `docs/01-需求分析.md`（v1.0）与设计方案 `docs/02-设计方案.md`（v0.1）
- 用户已确认的关键决策：
  - D1 舵机：8× MG90S PWM（LEDC 直驱，无反馈 → 软限位+堵转时间窗保护）
  - D2 控制：BLE 微信小程序（Nordic UART Service 协议 + 虚拟摇杆）
  - D3 传感器：仅 HC-SR04 超声波（无 IMU → 一键趴下替代跌倒自恢复）
  - D4 结构：乐高 Technic 积木 + 乐高兼容舵机支架先行
- 硬件要点：ESP32-S3-N16R8，LEDC 8通道 50Hz/14bit 驱动舵机（GPIO 4,5,6,7,15,16,17,18），HC-SR04（TRIG=38/ECHO=39 分压），2S 18650 + 5V/5A 独立舵机轨 + AMS1117 3.3V 主控轨，ADC 分压电量监测（GPIO10）
- 软件架构：ESP-IDF 5.x + FreeRTOS 六任务（servo/gait/ble/action/obstacle/monitor），事件组模式仲裁（PROTECT>ACTION>MANUAL>AUTO）
- 运动方案：波步（单腿摆动三轮支撑），8DOF 查表参数化，无逆运动学
- 里程碑：M0 固件骨架→M1 校准→M2 站立→M3 遥控爬行→M4 避障→M5 动作库→M6 外观联调
- 下一步：用户确认设计方案后进入 M0（固件工程骨架 + 小程序最小版）
