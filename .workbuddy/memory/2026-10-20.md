# 2026-10-20

## 交付：交互式教程站 `docs/tutorial/`

把「环境搭建 → VS Code 配置 → 编译烧写 → 验收 → 命令详解 → 错误处理 → main.c 讲解」编成可交互网页。

### 文件结构（纯静态，无构建、无外部依赖）
- `docs/tutorial/index.html` —— 外壳：顶栏（进度条/主题切换）、侧栏目录、主容器
- `docs/tutorial/style.css` —— 设计系统（CSS 变量 + 深浅两套），响应式，含打印样式
- `docs/tutorial/data.js` —— **全部内容数据**，`window.CHAPTERS` 数组，8 章
- `docs/tutorial/app.js` —— 渲染 + 交互逻辑

### 交互功能
- 8 章 / 41 个 h2 锚点，滚动高亮目录 + 自动展开当前章子目录
- 每章「标记已完成」、22 个验收勾选项 → localStorage 持久化
- 41 个代码块自动加语言标签 + 一键复制（clipboard + execCommand 兜底）
- 故障库搜索（Ctrl+K 聚焦）+ 5 个分类筛选 + 命中自动展开
- **日志判定器**：粘贴 `idf.py monitor` 输出 → 9 项检查（Flash/PSRAM/芯片/IDF 版本/分区完整性/心跳次数/min-free 波动/中文乱码/应用日志）
- 深浅主题、移动端抽屉目录、阅读进度条、回到顶部

### 关键技术坑（写进 data.js 时会踩）
- 内容放在 `String.raw` 模板里 → **PowerShell 的续行反引号 ` 会提前终止模板字符串**（本次真的踩了，node --check 报 `Unexpected identifier 'E'`）。解决：改用 HTML 实体 `&#96;`。
- 模板里 `E:\esp` 这类反斜杠必须靠 `String.raw` 保留，不能用普通模板字面量。
- `${` 会被当作插值 → 用 `$&#123;` 表示（tasks.json 片段里用到）。

### 验证方式
用 jsdom 做 DOM 集成测试（26 条断言全过）：章节渲染数、代码块数、进度持久化、判定器正/负样本、搜索/分类筛选、主题切换、C 代码 `#define` 不被高亮误判为注释。测试脚本用完即删。

### 维护入口
改内容只动 `data.js`；改样式只动 `style.css`；不要再往 `index.html` 里塞正文。
